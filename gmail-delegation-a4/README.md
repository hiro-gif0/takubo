# 社会部Gmail「代理アクセス」説明資料（A4・1枚）

社会部共通Gmailのパスワード共有をやめ、各自の会社Googleアカウントから社会部Gmailを使う
「代理アクセス」方式への切り替えを説明する、A4・1枚の配布資料です。

## ファイルの中身

| ファイル | 内容 |
|---|---|
| `gmail-delegation-a4.html` | 資料の本体（このファイルを開いて見る・印刷する） |
| `gmail-delegation-a4.pdf` | 印刷・配布用のPDF（あらかじめ変換済み） |
| `gmail-delegation-a4-preview.png` | 内容を画像でざっと確認できるプレビュー |
| `review-log.md` | 制作時の確認・修正の記録（社会部員が見る必要はありません） |

## HTMLの開き方

1. `gmail-delegation-a4.html` をダブルクリックする
2. ブラウザ（Chromeなど）が開き、A4サイズのレイアウトで表示される

## PDFの確認方法

`gmail-delegation-a4.pdf` をダブルクリックすれば、PDF閲覧ソフトやブラウザでそのまま開けます。
すでに変換済みのため、追加の作業は不要です。

もし将来、文言修正後に自分でPDFを作り直したい場合は、次の手順で作成できます。

1. `gmail-delegation-a4.html` をChromeで開く
2. `Ctrl + P`（Macは `Cmd + P`）で印刷画面を開く
3. 「送信先」を **PDFに保存** に変更する
4. 用紙サイズ：**A4**／余白：**なし**（または「デフォルト」）／拡大縮小：**100%**
5. 「背景のグラフィック」にチェックを入れる（色や枠がきちんと印刷されます）
6. 保存する

## 文言を修正する場所

`gmail-delegation-a4.html` をテキストエディタ（メモ帳や、なければ普通のエディタ）で開き、
`<body>` 以降にある日本語のテキスト部分を書き換えてください。デザイン（色や枠）を決めている
`<style>` 部分は触らなくても文言修正だけなら問題ありません。

修正後は、上の「PDFの確認方法」の手順で必ずPDFを作り直し、1ページに収まっているかを
実際にブラウザの印刷プレビューで確認してください（文章を増やすと2ページ目にはみ出すことがあります）。

## 印刷方法

1. `gmail-delegation-a4.html` をChromeで開く
2. `Ctrl + P`（Macは `Cmd + P`）で印刷
3. 用紙サイズ：**A4**／向き：**縦**／余白：**なし**（プリンタが対応していない場合は「最小」）／拡大縮小：**100%**
4. 「背景のグラフィック」にチェックを入れて印刷する（色が正しく出ます）

## 注意事項

- 実際のパスワードや個人名、社内メールアドレスなどの秘密情報は、このファイル一式のどこにも含まれていません。
- Google Workspaceの社内設定によっては、資料内の操作画面や表示名と実際の画面が異なる場合があります。分からない点は社内の「管理担当」「情報システム担当」に確認してください。
