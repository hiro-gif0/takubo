# 視覚設計ルール

画像生成プロンプトを作る際の参照資料。このファイルは変更しない。
変更が必要な場合は改善ログに記録してから更新する。

---

## 基本方針

- 新聞社の社内研修資料として自然な見た目
- PowerPointで人が丁寧に作ったような、清潔感のあるレイアウト
- 余白を多めに取る（上下左右最低40px）
- 1枚1メッセージ（複数のメッセージを1枚に詰め込まない）

---

## 禁止事項

- AI画像っぽい派手な装飾
- 過剰なグラデーション
- 意味の薄いアイコン（装飾目的のみのアイコン）
- 文字が小さすぎて読めないレイアウト
- 1画像に複数スライドを詰め込む

---

## 色ルール

| 色名 | カラーコード | 用途 |
|---|---|---|
| 濃紺 | #1A2B5F | タイトル・見出し・結論テキスト |
| 黄色 | #FFD700 | 重要キーワードのハイライト背景 |
| 緑 | #2E7D32 | 実践メソッド見出し・前向きな学び |
| 赤 | #C62828 | 注意点・誤解しやすい点・警告 |
| グレー | #757575 | 補足情報・サブテキスト・出典 |
| 白 | #FFFFFF | 背景（基本） |
| 極薄グレー | #F8F8F8 | 背景（バリエーション） |

---

## レイアウト仕様

| 項目 | 値 |
|---|---|
| スライドサイズ | 1280px × 720px（16:9） |
| 言語 | 日本語 |
| フォント | ゴシック系（メイリオまたは相当品） |
| タイトル文字サイズ | 32〜40px 相当 |
| 本文文字サイズ | 18〜24px 相当 |
| 注意ボックス文字サイズ | 16〜20px 相当 |
| 余白（上下左右） | 最低40px |

---

## 要素別デザイン仕様

### タイトルエリア（上部）
- 背景：白または濃紺
- テキスト：濃紺（背景白の場合）または白（背景濃紺の場合）
- サブタイトル：グレー

### 本文エリア（中央）
- 背景：白
- テキスト：ほぼ黒（#1A1A1A）
- 重要キーワード：黄色背景でハイライト

### 実例カード
- 左端に緑の縦帯（幅6〜8px）
- 「実例」ラベル：緑テキスト・小見出し
- 本文：黒テキスト
- 引用符なし・地の文で記述

### 注意ボックス（下部）
- 赤の細帯（下部ボーダーまたは左縦帯）
- 「！」アイコン：赤
- テキスト：赤
- 背景：薄いピンク（#FFF5F5）または白

### フロー図
- ボックス形状：角丸長方形
- ボックス背景：濃紺または緑（交互）
- テキスト：白
- 矢印：シンプルな実線・黒またはグレー

### 対比表
- 左列ラベル「▲ 注意」：赤
- 右列ラベル「◎ 実践」：緑
- 罫線：グレー
- 背景：白

### ステップ図
- ステップ番号：濃紺の円形バッジ・白テキスト
- ステップ説明：本文横に配置
- 縦積みレイアウト

## 完成スライド確認項目

- [ ] タイトルが読みやすいか
- [ ] 本文の文字が読める大きさか
- [ ] 色の使い方がルール通りか（6色以外使っていないか）
- [ ] 実例カードが本文と視覚的に分離されているか
- [ ] 注意ボックスが視覚的に分離されているか
- [ ] 余白が確保されているか
- [ ] 1枚1メッセージになっているか
- [ ] ファイルが1枚1ファイルになっているか
