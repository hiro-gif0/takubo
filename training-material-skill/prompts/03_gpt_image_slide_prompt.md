# プロンプト03：GPT Image スライド生成プロンプト

## 用途

工程6（図解スライド生成）で、GPT Image 2.0等に渡す画像生成プロンプトを作成する。
スライド台本（プロンプト02の出力）を1枚ずつ画像化するためのプロンプトを生成する。

---

## スライド共通設定（全スライドで必ず指定する）

```
以下の設定を全スライドのプロンプト冒頭に入れること：

---
[共通設定]
- サイズ：横1280px × 縦 720px（16:9）
- 言語：日本語
- 文字フォント：ゴシック系（メイリオまたは相当品）
- 背景：白または極薄グレー（#F8F8F8）
- デザインイメージ：新聞社の社内研修資料。PowerPointで人が丁寧に作ったような、清潔感のあるレイアウト。
- AI画像っぽい派手な装飾・過剰なグラデーション・意味の薄いアイコン：禁止
- 1スライド1メッセージを徹底する
---
```

---

## 色指定（必ず守る）

| 要素 | 色 | 用途 |
|---|---|---|
| 見出し・結論 | 濃紺 #1A2B5F | タイトル・強調テキスト |
| 重要キーワード | 黄色 #FFD700 | ハイライト・キーワード背景 |
| 実践メソッド・前向きな学び | 緑 #2E7D32 | メソッド見出し・実践ポイント |
| 注意点・誤解しやすい点 | 赤 #C62828 | 注意ボックス・警告テキスト |
| 補足情報 | グレー #757575 | サブテキスト・出典 |

---

## スライド別プロンプト生成ルール

台本の「図解形式」指定に応じて、以下のレイアウトを選択する。

### フロー図の場合

```
左から右（または上から下）への矢印フロー。
各ステップを角丸ボックスで表現。
ボックスの背景色は交互に濃紺と緑。
矢印はシンプルな実線。
```

### 対比表の場合

```
2列の対比レイアウト。
左列タイトル：「▲ 注意」（赤）、右列タイトル：「◎ 実践」（緑）。
各項目は罫線で区切る。
背景は白。
```

### ステップ図の場合

```
縦積みのステップ。STEP 01、STEP 02… と連番。
番号は濃紺の円形バッジ。
各ステップの説明は本文横に配置。
```

### 実例カードの場合

```
左端に縦帯（緑）を配置し、その右にエピソードテキスト。
見出しは「実例」と記載（緑テキスト）。
引用符はなし。地の文で記述。
```

### 注意ボックスの場合

```
スライド下部に赤の細帯で区切ったボックス。
左端に「！」アイコン（赤）。
テキストは赤で記載。
```

## プロンプト生成例（スライド04の場合）

台本：
```
タイトル：メソッド1 違和感をつかむ
ここがポイント：「変だな」という感覚を捨てない
本文：取材現場での違和感は、独自ダネへの入り口になる。
     「なぜここだけ違うのか」を問い続けることがメソッドの核心。
     違和感は気のせいではなく、情報の非対称性が生んでいる場合が多い。
実例カード：市の担当者が急に「答えられない」と言い始めた。その変化が記事の糸口になった。
図解形式：フロー図（違和感→問い→取材→記事）
注意ボックス：違和感を「礼儀的配慮」で押し込めない。
```

生成プロンプト：
```
[共通設定に従う]

タイトルエリア（上部）：「メソッド1 違和感をつかむ」（濃紺・大見出し）
サブタイトル：「『変だな』という感覚を捨てない」（中見出し・灰色）

中央エリア：左から右へのフロー図
 ボックス1：違和感（濃紺背景・白文字）
 ボックス2：「なぜ？」を問う（緑背景・白文字）
 ボックス3：取材・情報収集（濃紺背景・白文字）
 ボックス4：記事（緑背景・白文字）
 各ボックスを右向き矢印で接続。

実例カードエリア（中央右下）：
 左端に緑の縦帯。
 「実例」（緑文字・小見出し）
 「市の担当者が急に『答えられない』と言い始めた。その変化が記事の糸口になった。」（黒テキスト）

注意ボックス（下部）：
 赤の細帯ボックス。「！」アイコン（赤）。
 「違和感を『礼儀的配慮』で押し込めない」（赤テキスト）

全体の背景：白（#FFFFFF）
余白：上下左右40px以上
```

## 1枚生成後の確認事項

- [ ] 1画像＝1スライドになっているか
- [ ] テキストが読める解像度か
- [ ] 色の使い方がルール通りか
- [ ] 実例カードが本文と分離されているか
- [ ] 注意ボックスが視覚的に分離されているか
- [ ] ファイル名が連番か（例：slide_04.png）
