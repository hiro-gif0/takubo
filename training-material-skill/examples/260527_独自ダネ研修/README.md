# 使用例：独自ダネ研修（サンプル）

このフォルダは、Skillの使用例テンプレートです。
実際の教材を作成する際は、このフォルダ構成をコピーして使ってください。

## フォルダ構成例

```
260527_独自ダネ研修/
├─ README.md           ← このファイル
├─ improvement_log.md  ← 改善ログ（必須）
├─ transcript.txt      ← 元の文字起こし（必須）
├─ script/
│  ├─ slide_script.md  ← スライド台本
│  └─ fact_check.md    ← ファクトチェック結果
├─ slides/
│  ├─ slide_01.png     ← 生成したスライド画像
│  ├─ slide_02.png
│  └─ ...
└─ output/
   └─ training_material.pdf  ← 最終PDF
```
